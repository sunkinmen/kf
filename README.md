# 光復國小 校園探險王（PS5 實景 PBR 3D 闖關學習遊戲）

依**臺北市信義區光復國民小學**（光復南路 271 號）實景建築、校園公共藝術、周邊信義區地景，以及**光復國小夏季運動校服（白底藍條紋短袖上衣＋藍色運動短褲）**全面重製升級之 3D 校園探險遊戲。

## ✨ PS5 級實景與人物優化重點
1. **光復國小夏季運動校服實景還原**：
   - 男女學童及校園運動 NPC 全數換穿**短袖夏季運動校服**：**白底藍條紋短袖上衣**（含寶藍羅紋圓領、藍條紋短袖與羅紋袖口、左胸光復國小校徽與白底藍框學號名牌）搭配**寶藍色運動短褲**（含側邊雙白運動邊條）、白底雙藍圈運動長襪與藍白運動鞋。
2. **PS5 級 16 關節骨骼動作系統**：
   - 升級為完整多關節人體骨架（骨盆、脊椎胸腔、頸部、頭部、雙肩、雙肘、雙腕手掌、雙髖大腿、雙膝小腿、雙踝運動鞋）與馬尾物理擺動。
   - 支援**待機呼吸與重心微移**、**自然屈膝邁步**、**前傾擺臂衝刺（含動態 FOV 加速感與腳步煙塵粒子）**、**空白鍵／🦘 跳躍滯空與落地屈膝緩衝**、**轉彎離心傾角 (Banking)**。
3. **光復國小實景校園建築與大師藝術地標**：
   - **光復樓（圓樓）**：臺灣第一位女建築師**修澤蘭** 1966 年設計代表作，還原 16 根上寬下窄白色斬石子落柱、挑高出簷環形迴廊、三層圓弧窗帶、採光穹頂與 1F「布克斯王國」圖書室。
   - **修澤蘭 18 階旋轉樓梯**：還原圓樓南翼特色螺旋梯、內圈三支結構柱與柱頂環形樑。
   - **楊英風大師校園雕塑（1975）**：
     - **〈水袖〉景觀雕塑**：座落於圓樓（光復樓）正前方、椰林迎賓大道端景之 360 度上旋白色流線雕塑。
     - **〈光復—日光照大地〉不鏽鋼浮雕**：座落於面向校門之明德樓側牆，呈現太陽「日」字光芒照耀臺灣山岳。
     - **月門與幾何水池庭園**：座落於西南生態花園，結合傳統圓形月門、一米見方水泥踏板與鏡面反射生態池。
   - **全校真實校舍樓名**：**光復樓（圓樓）**、**和平樓**、**明德樓（行政大樓・4F 活動中心羽球場與外掛電梯）**、**忠孝樓**、**仁愛樓**、**信義樓**、**實踐樓**、**力行樓**、**自強樓**、**臺灣地圖屋頂專科教室**。
   - **信義區周邊地景天際線**：東側**國父紀念館**與中山公園、東南側**臺北 101 大樓**、北側**忠孝東路四段**與**捷運國父紀念館站**、西北側**臺北大巨蛋**、西側**光復南路 271 號正門**與大王椰子迎賓大道。
4. **次世代 PBR 物理光影與時段切換**：
   - 採用 ACES Filmic Tone Mapping、PMREM 物理環境反射、程序化凹凸紋理貼圖（斬石子、透水磚、PU 跑道、運動服針織紋）、柔和陰影與漂浮陽光微塵粒子。
   - 點擊右上角 **🌤️** 可即時切換「晴朗朝陽」、「璀璨午後」、「夕陽餘暉」三種校園光影時段。
